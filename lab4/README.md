# Лабораторная работа №4 — Наследование и полиморфизм

## Вариант 19 — Банк

Реализована иерархия банковских продуктов с абстрактным базовым классом `BankProduct`.

| Класс | Поля | Специальный метод |
|---|---|---|
| `Deposit` | `sum`, `rate`, `years`, `cumulative` | `isCumulative()` |
| `Credit` | `sum`, `rate`, `years`, `annuity` | `isAnnuity()` |
| `Card` | `spending`, `rate` | `hasCashback()` |

Метод `metric()` рассчитывает годовой финансовый показатель:
- **Deposit:** `sum * rate` без капитализации; с капитализацией — `sum * ((1 + rate)^years - 1) / years`.
- **Credit:** `sum * rate` без аннуитета; с аннуитетом — `12 * A`, где `A = sum * r / (1 - (1 + r)^(-n))`, `r = rate / 12`, `n = 12 * years`.
- **Card:** `spending * rate`.

Ставка хранится в долях единицы (`0.05` — это 5%). В консольном меню пользователь вводит её в процентах.

**Индивидуальное задание:** найти продукт с максимальной `metric()` за один проход по коллекции.

## Структура классов

```text
BankProduct (абстрактный класс)
├── Deposit
├── Credit
└── Card

BankCollection — коллекция банковских продуктов
```

`BankProduct` объявляет чисто виртуальные `metric()`, `print()`, `read()` и `clone()`.
Виртуальный деструктор обеспечивает корректное удаление наследников. Методы, не изменяющие объект, имеют `const`; переопределения обозначены `override`.

Свободные операторы `<<` и `>>` вызывают виртуальные `print()` и `read()`. Оператор `==` сравнивает метрики с точностью `1e-6`, а `operator double` возвращает метрику.

`BankCollection` хранит собственный динамический массив указателей `BankProduct**` и владеет копиями продуктов, полученными через `clone()`. Реализовано правило пяти: копирование создаёт независимые объекты, перемещение передаёт владение, деструктор удаляет объекты и массив.

Потоковый ввод принимает числовые поля в порядке таблицы (например, `100000 0.05 2 1` для вклада). Вывод содержит имя класса, поля и метрику; `read()` также умеет читать этот формат. Для логических полей используются `0` и `1`.

## Сборка

Из корня лабораторной работы:

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/lab04_main
```

В меню можно добавлять, просматривать и удалять банковские продукты, считать сумму метрик, находить максимум, сравнивать продукты и вызывать специальные методы через `dynamic_cast`.

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

В `tests/test_variant.cpp` проверяются формулы, специальные методы, `dynamic_cast`, операторы, чтение/вывод, копирование, перемещение, ошибки ввода, суммарная и максимальная метрика.

Для проверки памяти с AddressSanitizer (включая LeakSanitizer в Linux):

```bash
cmake -S . -B build-asan -DCMAKE_CXX_FLAGS="-fsanitize=address -fno-omit-frame-pointer" -DCMAKE_EXE_LINKER_FLAGS="-fsanitize=address"
cmake --build build-asan
ASAN_OPTIONS=detect_leaks=1 ctest --test-dir build-asan --output-on-failure
```
