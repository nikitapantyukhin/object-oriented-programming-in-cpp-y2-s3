# Лабораторная работа №3

**Вариант 13.** Множество температур (`TemperatureSet`) с динамическим массивом и перегрузкой операторов на C++20.

## Описание

Реализованы классы `Temperature` и `TemperatureSet`.

`Temperature` хранит значение температуры и единицу измерения (Цельсий, Фаренгейт, Кельвин). При сравнении температуры приводятся к единой единице измерения с фиксированной точностью.

`TemperatureSet` хранит уникальные температуры в динамическом массиве в порядке добавления.

## Возможности

- Добавление, удаление и поиск температур.
- Проверка дубликатов с учётом канонизации.
- Удаление элементов со сдвигом влево.
- Объединение, пересечение и разность множеств.
- Сравнение множеств независимо от порядка элементов.
- Перегрузка операторов `==`, `!=`, `()`, `+=`, `-=`, `|`, `&`, `-`, `<<`.
- Ручное управление динамической памятью с использованием правила пяти.
- Копирующее присваивание через copy-and-swap.
- Увеличение вместимости динамического массива в два раза.

```bash

cmake --build lab3/build
```

## Запуск

```bash

```

Программа предоставляет консольное меню для работы с двумя множествами температур `A` и `B`.

## Тестирование

Для тестирования используется Google Test. Тесты проверяют канонизацию, операции над множествами, копирование, перемещение, удаление с сохранением порядка и работу с дубликатами.

Запуск тестов:

```bash
ctest --test-dir lab3/build --output-on-failure
```

Проверка с AddressSanitizer и UndefinedBehaviorSanitizer:

```bash
cmake -S lab3 -B lab3/build-asan -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined -fno-omit-frame-pointer -g"
cmake --build lab3/build-asan
ctest --test-dir lab3/build-asan --output-on-failure
```
