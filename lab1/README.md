# Лабораторная работа №1

Вариант 12. Работа с C-строками и динамической памятью на C++.

В программе реализованы базовые операции над строками без использования `std::string`:

- создание динамической копии строки;
- вычисление длины строки;
- копирование содержимого строки;
- перевод строчных латинских букв в верхний регистр;
- подсчёт количества заданных символов;
- корректное освобождение выделенной памяти.

## Структура проекта

```text
lab1/
├── CMakeLists.txt
├── README.md
├── .gitignore
├── main.cpp
├── src/
│   ├── str_ops.h
│   └── str_ops.cpp

```

## Сборка

Из корня репозитория:

```bash
cmake -S lab1 -B lab1/build
cmake --build lab1/build
```

## Запуск

```bash
./lab1/build/lab01_main
```

## Тестирование

```bash
ctest --test-dir lab1/build --output-on-failure
```

Для проверки функций используется GoogleTest. В проекте предусмотрены тесты для обычных и граничных случаев, включая пустые строки и `nullptr`.

Проект собирается с использованием C++20 и CMake.
