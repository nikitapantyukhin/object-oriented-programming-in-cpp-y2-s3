
# Лабораторная работа №2

Вариант 9. Класс `Polynomial` с ручным управлением динамической памятью на C++.

В программе реализованы операции над многочленами без использования `std::string`, `std::vector`, `std::array` и умных указателей:

- создание многочлена из массива коэффициентов;
- нормализация коэффициентов и представление нулевого многочлена;
- глубокое копирование и перемещение объектов;
- управление динамической памятью по принципу RAII и правило пяти;
- присваивание через copy-and-swap;
- сложение и умножение многочленов;
- вычисление значения многочлена в заданной точке;
- возведение многочлена в неотрицательную целую степень (вариант 9);
- вывод многочлена в консоль.

## Сборка

Из корня репозитория:

```bash
cmake -S lab2 -B lab2/build
cmake --build lab2/build
```

## Запуск

```bash
./lab2/build/lab02_main
```

## Тестирование

```bash
ctest --test-dir lab2/build --output-on-failure
```

Для проверки класса используется Google Test. Предусмотрено 20 тестов на конструкторы, копирование, перемещение, присваивание, вычисления, операции с многочленами и метод `pow()`. Проверяются обычные и граничные случаи, включая нулевой многочлен, самоприсваивание и нулевую степень.

Для проверки ошибок работы с памятью можно собрать проект с AddressSanitizer:

```bash
cmake -S lab2 -B lab2/build-asan -DCMAKE_CXX_FLAGS="-fsanitize=address -fno-omit-frame-pointer" -DCMAKE_EXE_LINKER_FLAGS="-fsanitize=address"
cmake --build lab2/build-asan
ctest --test-dir lab2/build-asan --output-on-failure
```
